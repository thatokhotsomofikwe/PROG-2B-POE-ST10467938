# PROG-2B-POE-ST10467938

RaceDay

South African Road Running, Walking and Cycling Event Management System

RaceDay is a planned web-based event management system designed to support road running, walking and cycling events in South Africa.

The current project focuses on Planning and System Design. The repository contains the initial database design, API planning, project documentation and Continuous Integration setup.

README.md

Provides an overview of the RaceDay project and its current development stage.

RaceDay.pdf

Contains the Entity Relationship Diagram (ERD) for the planned RaceDay database. The ERD shows the main entities, attributes, primary keys, foreign keys and relationships.

RaceDay_API_Endpoint_Plan.md

Contains the planned REST API endpoints for the RaceDay system, including the HTTP methods, routes, descriptions and user roles.

RaceDay_Database.sql

Contains the SQL Server database script for creating the planned RaceDay database structure, including tables, relationships, constraints and sample data.

.github/workflows/ci.yml

Contains the GitHub Actions Continuous Integration workflow used to automatically check the project when changes are pushed to the repository or pull requests are created.
