RaceDay System Requirements

1. Introduction

RaceDay is a planned web-based event management system for South African road running, walking and cycling events.

The system will provide a centralised platform where Event Organisers can manage sporting events and Participants can discover and enrol in events.

This document outlines the main requirements identified during Part 1 — Planning and System Design.



2. User Requirements

Organiser

The system should allow an Organiser to:

Create sporting events.
Update event information.
Delete events.
Create event categories.
Update event categories.
Delete event categories.
View participant enrolments.
Capture participant results.
Update participant results.
Manage event route information.

Participant

The system should allow a Participant to:

Create an account.
Log into the system.
Browse upcoming events.
View event information.
Select an event category.
Enrol in an event.
View their enrolments.
Cancel an enrolment where permitted.
View their personal results.
View event route information.
View available weather information.



3. System Requirements

RaceDay is planned to include:

A web-based user interface.
  A RESTful ASP.NET Core Web API.
  A Microsoft SQL Server database.
  User authentication.
  Role-based authorisation.
  Event management functionality.
  Event category management.
  Participant enrolments.
  Participant results.
  Route information.
  Weather information.
  Swagger/OpenAPI documentation and testing.
  GitHub version control.
  GitHub Actions Continuous Integration.
